# Hausärzte Trier - Website

Website für die Hausarztpraxis in Trier, entwickelt mit Svelte 5 und Tailwind CSS.

## 🏥 Über das Projekt

Diese Website dient als digitale Präsenz für die Hausarztpraxis in Trier. Sie bietet Patienten und Interessenten wichtige Informationen über:

- **Praxisinformationen**: Sprechzeiten, Kontaktdaten, Anfahrt
- **Team**: Vorstellung der Ärzte und des Praxisteams
- **Leistungsspektrum**: Übersicht der angebotenen medizinischen Leistungen
- **Aktuelle Neuigkeiten**: Wichtige Updates und Informationen
- **Urlaubszeiten**: Schließzeiten der Praxis

## 🛠️ Technologie-Stack

### Frontend

- **[Svelte 5](https://svelte.dev/)** - Modernes Frontend-Framework
- **[SvelteKit 2](https://kit.svelte.dev/)** - Full-Stack Web Framework
- **[Tailwind CSS 4](https://tailwindcss.com/)** - Utility-First CSS Framework
- **[TypeScript](https://www.typescriptlang.org/)** - Typisierte JavaScript-Entwicklung

### Build Tools

- **[Vite 7](https://vitejs.dev/)** - Schneller Build-Tool und Dev-Server
- **[PostCSS](https://postcss.org/)** - CSS-Transformationen
- **[Sass](https://sass-lang.com/)** - CSS-Präprozessor

### Datenmanagement

- **Google Sheets Integration** - Dynamische Inhaltsverwaltung
- **Server-Side Rendering (SSR)** - Optimale Performance und SEO

## 🚀 Schnellstart

### Voraussetzungen

- **Node.js** (Version 22.14.0 oder höher)
- **npm** (wird mit Node.js installiert)

### Installation

1. **Repository klonen**

    ```bash
    git clone [repository-url]
    cd hausaerzte-trier
    ```

2. **Abhängigkeiten installieren**

    ```bash
    npm install
    ```

3. **Entwicklungsserver starten**

    ```bash
    npm run dev
    ```

4. **Website öffnen**
   Öffnen Sie [http://localhost:5173](http://localhost:5173) in Ihrem Browser.

## 🎨 Design-System

### Farbpalette

Die Website verwendet eine maßgeschneiderte Grün-Farbpalette:

- **Gulfstream-400**: `#6c9b70` (Hauptfarbe)
- **Gulfstream-500**: `#4b7e51` (Akzentfarbe)
- **Gulfstream-100**: `#e0ecdf` (Hintergrund)
- **Gulfstream-50**: `#f2f7f2` (Seitenhintergrund)

### Typografie

- **Schriftart**: Roboto (alle Gewichtungen)
- **Responsive Design**: Mobile-First Ansatz
